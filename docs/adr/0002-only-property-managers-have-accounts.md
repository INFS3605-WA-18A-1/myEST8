# Only Property Managers have accounts

Tenants, Tradies and Property Owners never sign up or log in to myEST8. Every interaction with them (reporting issues, quoting, approving, scheduling, rating) happens over the channels they already use: email, SMS and WhatsApp, read and answered by the intake agent. We chose this over a tenant portal and tradie accounts because sign-up friction would stop tenants reporting issues and most tradies would never adopt another app. The cost is that every flow has to work through free-form messages, so the agent must parse replies (quotes, approvals, time changes) that a form would have captured cleanly. The one exception is photo uploads: the agent sends a no-login upload link by SMS or WhatsApp, because those channels compress photos and strip their metadata. The upload page has had no security review yet.
