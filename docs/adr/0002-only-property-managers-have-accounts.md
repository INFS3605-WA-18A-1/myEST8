# Only Property Managers have accounts

Tenants, Tradies and Property Owners never sign up or log in to myEST8. Every interaction with them (reporting issues, quoting, approving, scheduling, rating) happens over the channels they already use: email, SMS and WhatsApp, read and answered by the intake agent. We chose this over a tenant portal and tradie accounts because sign-up friction would stop tenants reporting issues and most tradies would never adopt another app. The cost is that every flow has to work through free-form messages, so the agent must parse replies (quotes, approvals, time changes) that a form would have captured cleanly. The first exception is photo uploads: the agent sends a no-login upload link by SMS or WhatsApp, because those channels compress photos and strip their metadata. The same kind of link takes a Tenant's Urgent Repair receipt, as a photo or PDF. The upload page has had no security review yet.

The Tenant's progress tracker is a second exception of the same kind. When a Property Manager confirms a Maintenance Request, the confirmation message carries a no-login link to a page showing where the Ticket is up to (Reported, Confirmed, Getting quotes, Approved, Booked, Done, Closed). Like the upload link, it is an unguessable link for one item, so a Tenant can check progress without messaging the Agency or creating an account. It never shows prices, Quotes or Tradie ratings. It has had no security review yet either.
